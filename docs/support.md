# Support and licensing

## Support

- For defects or feature requests concerning this implementation, open an issue
  in the
  [Amazon Braket QDMI Device repository](https://github.com/munich-quantum-software/amazon-braket-qdmi-device/issues).
- For the interface specification, consult the
  [QDMI repository](https://github.com/Munich-Quantum-Software-Stack/QDMI).
- For service configuration and device availability, consult the
  [Amazon Braket documentation](https://docs.aws.amazon.com/braket/).

Do not include AWS access keys, session tokens, credentials files, or other
secrets in an issue report.
